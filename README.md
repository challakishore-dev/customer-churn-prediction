## 📌 Project Overview

Customer churn refers to customers who stop using a company's product or service.

For businesses such as telecom, SaaS, OTT platforms, fintech, and subscription services, customer retention is critical. Acquiring new customers is significantly more expensive than retaining existing ones.

This project uses Machine Learning to predict churn risk based on customer behavior, billing, and support patterns.

---

## 🎯 Business Objective

The goal of this project is to help companies:

* Identify high-risk customers early
* Reduce customer loss
* Improve retention campaigns
* Increase recurring revenue
* Optimize support and marketing efforts

## ⚙️ Installation & Run

## 1️⃣ Clone Repository

```bash id="5m4a4t"
git clone https://github.com/challakishore-dev/customer-churn-prediction.git
cd customer-churn-prediction
```

## 2️⃣ Install Libraries

```bash id="r1vzxz"
pip install -r requirements.txt
```

## 3️⃣ Train Model

```bash id="a8xvq7"
python train.py
```

## 4️⃣ Run Dashboard

